# qrip
QRIP is a professional qualitative research workspace. It is an automatic coding platform: it codes interview transcripts and documents, supports thematic analysis and other structured analysis passes, builds themes, surfaces contradictions / tensions, and produces a draft readout / report. Researchers can review and manually change codes at any time. Judgment stays with the human; QRIP prepares the first pass. Core job: turn qualitative material (interviews, transcripts, documents) into codes, themes, patterns, contradictions, and a usable draft report — faster than fully manual coding, without replacing the researcher. Accessible here: https://qrip-research-hogb.onrender.com
